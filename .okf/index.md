# rails-api-docs knowledge bundle

Knowledge, decisions and documentation for the `rails-api-docs` gem. Start with the [pipeline](overview/pipeline.md).

# Areas

* [Overview](overview/) - End-to-end pipeline and glossary.
* [Inspection](inspection/) - Route, controller (Prism), schema and JSON-route inspectors that feed the scaffold.
* [Config](config/) - The YAML contract, how it is built, merged append-only and loaded; global configuration and filters.
* [Rendering](rendering/) - YAML → self-contained HTML: renderer, template, cURL, sample values.
* [Distribution](distribution/) - How users run it: generators, dev mount, build task.
* [Decisions](decisions/) - Why the gem works the way it does.
* [Pitfalls](pitfalls/) - Traps that already bit (or will bite) contributors.
* [Operations](operations/) - Testing, releasing, known limitations.
